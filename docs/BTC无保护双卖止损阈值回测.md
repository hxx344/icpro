# BTC 无保护双卖：止损阈值回测

本次数据和成交假设下，按费后总收益排序，**不止损最好；没有找到优于不止损的止损阈值**。65 个止损阈值中，350%、400%、500%、750%、1000% 并列最好，但都只触发同一笔平仓，不能据此认定 350% 是可推广的精确最优点。

完成日期：2026-10-09。数据期：2023-03-20 至 2026-03-24，时间均为 UTC，金额均为 USD。

## 策略与共同样本

按用户提供的 `D:/project_greeks` Bybit 策略选卖腿，去掉两条保护腿。每周五 21:00 选择周日 08:00 到期、绝对 Delta 最接近 0.45 的 Call 和 Put，每腿卖出 1 BTC。保留原代码的 `Put strike < Call strike` 条件；先选最接近的合约，再检查盘口，不因流动性不足改选更远 Delta，也不延后到 22:00 或 23:00 重新开仓。

157 个计划周末中，共 72 组、144 条腿成交。70 周因卖腿行权价重合或交叉跳过，12 周卖出盘口数量不足，3 周入场报价缺失。全部阈值使用相同的 72 组开仓，不能直接与先前 151 组铁鹰结果比较。

固定每腿数量，不复利、无 Delta 对冲、无额外止盈。没有继承原铁鹰的 2,500 美元有限最大风险条件，也不模拟保证金约束或强平；报告是固定数量损益，不是账户收益率。

## 止损定义与成交

用户选择的口径为“两腿合计亏损 ÷ 开仓净收权利金，整组止损”。本实现把费用一并计入：

```text
C = 两腿开仓 bid 收入 − 开仓手续费
D(t) = 两腿当前 ask 回购成本 + 平仓手续费
亏损比例 = [D(t) − C] / C
触发条件：亏损比例 ≥ 止损阈值
```

例如净收 1,000 美元，100% 止损代表两腿含手续费回购成本达到 2,000 美元；350% 代表达到 4,500 美元。

开仓后的首个检查点是周五 22:00，此后每小时检查，最后为周日 07:00。周日 08:00 按交割结算。开仓按 bid、平仓按 ask，均要求整组两腿盘口数量达到各 1 BTC，使用该小时起始 60 秒内的真实快照。没有用 mark、理论价或阈值价代替成交价。

触发止损后锁定平仓意图。若两腿数量不足，继续到下一小时；即使报价恢复、亏损比例回落，也在首次能够整组成交时平仓。缺失报价时无法判断是否新触发，已触发的意图继续保留。若到期前仍不能成交，照常交割，不丢弃该周，也不把实际亏损截断在阈值。

## 数据及费用

本地可用历史是 **Deribit 小时盘口**，用于近似给定的 Bybit 策略；不能还原原策略每秒调整 BBO、最多等待 600 秒的挂单行为。币本位报价按当小时 BTC 现货 open 折算 USD。

统一使用 Bybit 当前 VIP 0 taker 假设：交易费为 `min(0.03% × 标的价格, 7% × 期权价格) × 数量`。主结果对实值到期腿收取 `min(0.015% × 交割价格, 12.5% × 内在价值) × 数量`，价外交割费为零。官方说明每日到期期权免交割费，所以另做全部免交割费敏感性分析。这里没有复原历史会员等级及历史费率。[Bybit 期权费用说明](https://www.bybit.com/en/help-center/article/Bybit-Option-Fees-Explained)

不止损组开仓费合计 2,562.28 美元，交割费 440.27 美元，均已扣除。144 条到期腿中，138 条有对应合约交割记录，6 条使用到期小时现货 open 兜底。5,040 条持仓腿小时快照中有 11 次无法用于判断止损，实际快照最大延迟 46.73 秒；没有沿用旧 mark 的观测。

回撤从每小时 mark 计价损益计算，包含入场费和已发生的平仓/交割费；不按周末终值掩盖持仓期间回撤。夏普使用每天 21:00 UTC 的 USD 损益，保留空仓日、按 365 日年化，不是保证金收益率夏普。

15% 是网格内全期回撤最小的阈值：回撤比不止损少约 50.7%，但利润也少约 85.5%。它的后段验证期亏损 1,093.84 美元，因此不能仅凭较小的全期回撤选用。

## 影响结论的交易

100% 止损共平仓 16 次，其中只有 1 次比持有到期更好，15 次更差，合计少赚 14,211.05 美元。例如 2024-04-12 开仓的一组，次日 21:00 首次可见触发时实际亏损已经达到净收权利金的 306.55%，平仓亏 4,092.65 美元；该组持有到期亏 1,096.92 美元。小时采样和盘口价差会使实际亏损明显穿过阈值。

宽阈值组的唯一触发来自 2024-07-20 09:00：`BTC-21JUL24-67000-P` 的 ask 约 39,612.72 美元，但卖盘只有 0.1 BTC。10:00 价格已回落，但数量仍不足；11:00 才满足整组平仓条件。最终仍赚 157.74 美元，比持有到期少赚 494.10 美元。所有宽阈值都被这次极宽价差触发，所以它们的同值结果不是稳定止损点的证据。

上述原始报价保留在 `quote_audit.csv`；每个阈值的 `packages.csv` 都记录首次触发时间、延迟小时、实际亏损比例和超出阈值的幅度。

## 时间顺序验证与费用敏感性

按计划周末时间顺序划分前 80% 为训练区间，在查看后段表现前保存选参结果；训练实际成交 59 组，验证实际成交 13 组，验证起点为 2025-08-15 21:00 UTC。选参排序为净收益最高、回撤更小、阈值更低。

训练区间选出“不止损”：训练净赚 22,135.48 美元，验证净赚 3,141.67 美元。只比较止损组，训练区间同样是 350%～1000% 并列最好，验证区间这些阈值均未触发止损，无法提供其保护效果的证据。

100% 止损在验证期净赚 3,564.99 美元，比不止损多 423.32 美元，但仅由一笔止损改善；它在训练期净收益只有 7,501.11 美元，不能事后用这 13 组反选参数并称为验证通过。

这份结果支持“当前样本与成交规则下，未找到有收益优势的止损阈值”，不支持把裸卖不止损当作已验证的实盘方案。样本只有 72 组，且不覆盖保证金强平、小时内穿越及真实 Bybit 挂单执行。
