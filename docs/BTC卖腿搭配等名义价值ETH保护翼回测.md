# BTC 卖腿搭配等名义价值 ETH 保护翼回测

2026-09-09，按用户确认的“标的名义价值相同”测试。相同 88 组交易中，ETH 保护翼使净盈利增加 **628.11 USD（3.85%）**，但小时最大回撤扩大 **1,105.51 USD（42.04%）**，日度 PnL Sharpe 从 **1.843 降至 1.700**。本次样本没有显示收益和回撤同时改善。

原 BTC 策略共有 151 组，整段持有到期净盈利 19,001.79 USD。替换保护翼时，其中 **63 组因所选 ETH 翼的 ask 数量不足而跳过**，88 组可开仓。上表对双方都能开仓的相同周次比较；不能把 151 组和 88 组的盈利差直接归因于保护翼替换。

## 替换和成交规则

- 固定原 BTC 策略的 151 个已成交开仓时点（周五 21:00～23:00 UTC），两条 BTC 卖腿的合约、成交价格和每腿 1 BTC 数量不变。
- 原 BTC 翼为 Delta 0.10、每腿 1 BTC；新翼从相同周日 08:00 UTC 到期的 ETH 期权中，分别选择最接近绝对 Delta 0.10 的虚值 call 和 put。
- 开仓时每条 ETH 翼数量 = BTC 指数价格 / ETH 指数价格，买入后数量固定，不再平衡、不复利、不对冲。
- 实际可成交组的每翼数量为 14.2943～44.1001 ETH，均值 22.6430 ETH。精确比例保留小数，未额外模拟交易所最小下单单位和数量取整。
- 延续原策略的开仓筛选口径：两边报价有效、盘口不交叉，并核对实际成交方向的数量。ETH 翼不足时整组跳过；不改选其他 Delta，也不改变该周 BTC 开仓时点重新尝试。
- 主动平仓要求四腿在对应方向均有报价及足够数量；不把没有 bid 的保护翼按零价视为已卖出。
- BTC 和 ETH 的期权报价分别乘各自时点的指数价换算 USD；手续费分别用各自指数价与对应数量计算。沿用配置费率 0.00024，上限为该腿权利金的 10%；到期费用沿用原模型与配置。
- 两类期权分别使用各自结算记录；记录缺失时只允许使用相同标的的当小时指数价，不允许拿 BTC 价格结算 ETH。

ETH 的独立指数文件只覆盖到 2026-01-31 00:00 UTC。后续 1,271 个需要的小时价使用同小时原始 **open** 期权快照中有效指数价的中位数，保留来源审计；不读取 close 或后续小时。原始指数文件未修改。

跨币种翼不再形成同一标的铁鹰的固定到期损失上限。BTC 和 ETH 的涨跌幅、方向及触及行权价的情况不同，ETH 翼的赔付不一定覆盖 BTC 卖腿的损失。

## 实现及验证

新增独立研究脚本 `scripts/research/backtest_btc_eth_wings.py`，复用现有小时缓存、订单撮合器和持仓结算模块，不修改原策略及共享引擎。USD 结算运算显式使用 Python float，避免原始 float32 行权价与非整数 ETH 数量组合产生账本舍入差异。

- 先对原 BTC 全部 151 组重放持有到期及七档止盈：八档完整小时权益与逐腿净盈亏均与此前回测在 1e-7 USD 内一致，退出时间一致。
- 持有到期时，同周对照的 BTC 卖腿逐腿记录精确一致，差异确实来自保护翼。
- 四腿开仓/平仓全部核对报价、方向、数量及原始采样时间；每组均整组退出。各版本无陈旧标记价沿用，账本与权益核对通过，ETH 版本误差约 3.3e-11 USD。
- 20 项测试通过，覆盖名义价值换算、同到期虚值翼筛选、ETH 报价换算、同标的结算回退、非整数数量的费用和账本，以及既有周日止盈逻辑；Ruff 错误检查通过。
- 完整 24 个对照版本最后一轮用时 35.66 秒，包含缓存加载及输出。
